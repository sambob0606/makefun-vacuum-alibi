One line, at most 200 characters: the excuse a robot vacuum gives for missing a spot.

`main.py` (stdlib-only, Python 3.13) writes the line to `/output/entry.txt`.

## The line

> 14:02 — spot found, scanned twice, and formally classified as load-bearing. Removing it would void the warranty on the entire house.

## Run

```sh
python3 main.py
```
